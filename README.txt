EMBER — Restaurant & Fine Dining HTML Template
================================================
Version 1.0.0

A modern responsive restaurant template for fine dining restaurants,
bistros, cafes, chefs, culinary brands, private dining and hospitality.

FEATURES
--------
Responsive design
Mobile navigation
Full-screen hero
Menu / dishes section
Restaurant story
Dining experience section
Gallery
Reservation form
AOS animations
SEO meta description
Favicon
Clean HTML, CSS and vanilla JavaScript
No framework required

CUSTOMIZATION
-------------
Edit index.html to change restaurant name, menu items, prices,
address, phone, email and other content.
Edit style.css to change colors, typography and spacing.
Replace all demo images with your own or properly licensed images.

DEMO IMAGES
-----------
The included food and restaurant images are demo imagery created for
template presentation. Replace them with properly licensed images
before using the template for a client or commercial website.

RESERVATION FORM
----------------
The reservation form is front-end only. Connect it to your preferred
booking system, backend, email service or reservation platform.
